## Iniciando

1. Tenha o golang instalado, verificar com o comando abaixo(recomendado versão 1.25):
```shell
    go version
```
2. Clone o projeto.
```shell
    git clone https://github.com/BrunoPessoa097/api-go-simples.git
```
3. Dentro da pasta iniciar esse comando:
```shell
    go mod tidy
```
4. ir para a pasta `cmd/api`:
```shell
    go run
```
